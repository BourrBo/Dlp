DLP Guard settings

Organization settings can be centrally managed by your administrator. The extension sends scans to the configured DLP API and does not send organization or user IDs from the browser.

Some settings are controlled by your administrator and cannot be changed here.
Use HTTPS for hosted deployments. Local development can use http://localhost:8000.
A key provided by your administrator is preferred. A local key is stored in this browser profile and is not synced.
Personal sign-in (used only when no API key is set)
Your organization is taken from your account. The password is sent only to Supabase and is never stored.
One domain per line. Content scripts are limited to the sites declared in the extension package.
Protection
An administrator-managed fail-open/fail-closed setting takes precedence.
